How it works

1. The Drive REST API lists every image in the folder tree using your key.
2. Each image is downsampled to 1024px max and sent to Gemini, which returns a name, color palette, likely materials, size guess, story, and a mockup flag.
3. ExcelJS assembles one sheet per top-level subfolder. Mockups are skipped by default.
Nothing leaves your browser except the Drive and Gemini API calls.

One-time setup (Google API key + folder sharing)
  1. Open console.cloud.google.com and create (or pick) a project.
  2. APIs & Services → Library: enable Google Drive API and Generative Language API.
  3. APIs & Services → Credentials → Create credentials → API key. Copy it.
  4. (Optional but recommended) Restrict the key: API restrictions → the two APIs above; Application restrictions → HTTP referrers → add file://* if opening this HTML locally.
  5. Right-click the Drive folder → Share → Anyone with the link — Viewer. Subfolders inherit.
  6. Paste the folder URL and the key above. Click Build catalog.
